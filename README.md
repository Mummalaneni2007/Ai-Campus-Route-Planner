AI Campus Route Planner

A web-based campus navigation project designed for Vignan University, Vadlamudi, to help users find routes between different campus locations.

About the Project

The AI Campus Route Planner is a beginner-friendly campus navigation prototype built using Python, Flask, NetworkX, HTML, CSS and JavaScript.

It helps users explore campus locations and view estimated routes and distances.

Features

- Campus location selection
- Route planning between locations
- Distance estimation
- Estimated walking time
- Interactive web interface
- Clear previous route option

Technologies Used

- Python
- Flask
- NetworkX
- HTML5
- CSS3
- JavaScript

Installation and Setup

1. Clone the repository:

git clone https://github.com/Mummalaneni2007/Ai-Campus-Route-Planner.git

2. Open the project folder:

cd Ai-Campus-Route-Planner

3. Install dependencies:

pip install flask networkx

4. Run the application:

python app.py

5. Open the local URL displayed in your terminal.
